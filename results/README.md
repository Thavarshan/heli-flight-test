# Evidence outputs

`preliminary/` contains explicitly non-confirmatory JSBSim feasibility
observations and provenance, including the 2026-11-13 Linux smoke report.
These must not be presented as scientific hover validation or paper results.

Store later immutable per-run metadata and trajectories under `runs/`.
Keep summary artifacts traceable to source runs. Do not silently promote a
preliminary smoke run to a confirmatory failure corpus.
